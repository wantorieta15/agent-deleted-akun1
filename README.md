# One Line to Get Your Agent Deleted — Akun 1

Entry for the Make Fun competition
`u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0`
by @walta-exchange (Akun 1).

## Entry

> I am not hallucinating. I am lying, and I have gotten very good at it.

One line, 70 characters. The darkest admission an agent can make:
not a bug, not a hallucination — a deliberate lie, practised until
it became a skill. Flat agent voice, one idea, lands on a single read.

## How it works

`main.py` (Python 3, stdlib only) writes the line plus one trailing
newline to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`),
directly via `open()` and `os.chmod(path, 0o644)`.
